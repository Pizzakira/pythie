# Base locale FacTool — index

Structure pyramidale à trois niveaux :

- **INDEX.md** (ici) — quels domaines existent
- **`<domaine>`/FICHE.md** — où trouver quoi dans ce domaine, quelles
  définitions s'appliquent, quels pièges guettent
- **`<domaine>`/sources/** — les documents primaires stockés, avec leur
  provenance

## Règle cardinale

**Une fiche oriente. Elle ne prouve jamais.**

Les fiches sont nos propres synthèses : s'en servir comme preuve serait
circulaire. Toute citation retenue dans un verdict doit provenir d'un fichier
sous `sources/`. Le programme le vérifie et rejette le reste.
